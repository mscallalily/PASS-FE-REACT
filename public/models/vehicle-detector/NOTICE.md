# Vehicle detector model

TensorFlow.js COCO-SSD / SSD Lite MobileNet V2, from TensorFlow Authors.

Model: https://storage.googleapis.com/tfjs-models/savedmodel/ssdlite_mobilenet_v2/model.json
Implementation: https://github.com/tensorflow/tfjs-models/tree/master/coco-ssd

Redistributed locally with the Apache 2.0 license in LICENSE.txt. SHA256.json records the downloaded weight shards. The pretrained detector distinguishes broad object categories; it is not trained to verify Philippine plates, vehicle ownership, exact wheel count or paint names. Color estimates are separate application logic. No private photo or school ID is included in these assets.
